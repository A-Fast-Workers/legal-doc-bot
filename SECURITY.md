# Безопасность

- Никогда не коммитьте `.env`, токен бота и ключ GigaChat. Если ключ попал в репозиторий, немедленно перевыпустите его (@BotFather → `/revoke`, личный кабинет GigaChat).
- Документы пользователей хранятся только в памяти процесса и не пишутся на диск; логи не содержат текста документов.
- Для постоянной работы используйте `GIGACHAT_CA_BUNDLE` вместо `GIGACHAT_VERIFY_SSL=false`.
- Об уязвимостях сообщайте владельцу репозитория приватно (через Security → Report a vulnerability на GitHub).
